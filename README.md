# carlocancellieri

Landing page per una società di produzione di cortometraggi.

## Struttura
- `assets/` materiali che finiscono nel sito: `logo/`, `foto/`, `video/`, `font/`
- `reference/` ispirazioni, non destinate alla pubblicazione: `siti/` (screenshot e link), `moodboard/`, `film/` (frame, locandine), `tipografia/`
